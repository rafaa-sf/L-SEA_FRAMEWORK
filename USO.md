# Uso

## Instalación y desarrollo
```bash
npm install
python descargar_lola.py   # genera public/data/lola_shackleton.bin
npm run dev                # http://localhost:5173
```

## Build producción
```bash
npm run build
```

## Validación física (tests)
```bash
node tests/verify.mjs
```

## Preview build
```bash
npm run preview
```
