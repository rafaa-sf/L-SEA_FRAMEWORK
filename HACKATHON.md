# HACKATHON.md

**Propósito**: Checklist personal de 48h para el NASA Space Apps Challenge 2026 (Málaga).

**Cuándo leerlo**: Durante el evento (los 2 días del hackathon) para no perder el foco. Después del evento, sirve de registro de qué se construyó.

**Qué contiene**: Lista de features a implementar, supuestos a documentar, y validaciones a pasar. Se marca `[x]` conforme se completa.

**Base de partida**: El motor en `src/core/` + `src/3d/` (ver `README.md` → Créditos y Código Previo).
